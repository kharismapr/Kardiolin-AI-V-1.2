═══════════════════════════════════════════════════════════════════════════

User Action in Java GUI
         ↓
Check if file loaded (216+ samples)

Extract 216-sample window from ECG data

Calculate R-R intervals from signal peaks
         ↓
Prepare JSON payload:
{
  "signal": [sample1, sample2, ..., sample216],
  "rr": [rr_interval1, rr_interval2]
}
         ↓
Send HTTP POST to http://localhost:5000/predict
         ↓
Flask Backend Receives Request
         ↓
Validate input (216 samples required)
         ↓
Z-score normalize the signal
         ↓
Reshape to (1, 216, 2) for ONNX model
         ↓
Run ONNX inference
         ↓
Get prediction and confidence score
         ↓
Return JSON response:
{
  "prediction": "N",
  "confidence": 0.95
}
         ↓
Java receives response
         ↓
Display in MainDashboard window
         ↓
User sees: "Diagnosis: Normal (95% confidence)"

                            TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

ISSUE: Can't find MainDashboard window
SOLUTION:
  1. Check taskbar/dock for Java window
  2. Window might be behind other apps - bring to front
  3. If truly missing, restart Java:
     cd /Users/shasya/Downloads/projectECG
     export PATH="/opt/homebrew/opt/openjdk/bin:$PATH"
     java -cp build/projectECG.jar:lib/jSerialComm.jar projectecg.ProjectECG &

ISSUE: "Connection refused" when analyzing
SOLUTION:
  1. Verify Flask is running:
     lsof -i :5000
  2. If not, restart Flask:
     killall python
     cd /Users/shasya/Downloads/projectECG
     ./.venv/bin/python modelekg.py &
  3. Wait 2 seconds for Flask to start

ISSUE: "Signal too short" error
SOLUTION:
  1. Your CSV file must have 216+ samples
  2. At 125 Hz: 216 samples = 1.73 seconds
  3. Check file has enough rows of data

ISSUE: Prediction takes too long (>5 seconds)
SOLUTION:
  1. First request loads model - it's slower
  2. Subsequent requests are ~1-2 seconds
  3. Check network/system load
  4. Restart Flask if consistently slow
